Cookie 设置（仅遇到 Fresh cookies / 风控时使用）

粘贴抖音网页 Request Headers 中 Cookie: 后面的完整值。只发送到你自己的 Render 服务，不写入 GitHub。

AI 设置（完整版语音转写 + 专业视频分析）

如果 Render 已配置 OPENAI_API_KEY，这里留空即可；否则可临时填写自己的 API Key。Key 只用于当前“完整版文字/视频分析”请求，不写 GitHub，也不存进视频解析令牌。

AI Key 未配置：有字幕的视频仍可提取完整字幕；无字幕视频需要 Key 才能做完整语音转写和专业分析。
不要把 API Key 发到聊天、截图或公开仓库。

下载视频打开原作品

① 下载素材

自动处理普通 MP4、HLS、分离音视频与防盗链回退。

② 完整版文字

优先读取完整字幕；无字幕时按 45 秒分段做完整语音转写，减少长视频漏句。

③ 专业视频分析

复用完整版文字，并结合最多 7 个关键帧分析钩子、结构、人物、镜头、节奏和爆点。

完整版文字
结果分为“作品标题 / 作品文案 / 完整字幕或语音转写”。优先保证完整，不做激进去重。
